💡 Real-World Usage Examples
When OpenZL is used:
• Server-to-server communication (microservices)
• Mobile apps with custom SDKs
• High-performance web apps with WASM decompression
• Data pipelines and ETL processes

When OpenZL is NOT used:
• Regular web browsers (no native support)
• Standard HTTP clients (Postman, curl, fetch)
• Third-party integrations without OpenZL support

Solution for browsers:
• Use gzip/deflate for web clients
• Implement WASM-based decompression
• Use server-side decompression proxy
• Provide both compressed and uncompressed endpoints
